关于我

你好，我是 Hongyu，一名全栈开发者。

从 2019 年参加工作至今，持续从事企业业务系统与应用开发。主要使用 Java、Python 和 Vue，工作内容涵盖后端服务、前端页面、移动端应用，以及设备对接和自动化工具。

我更关注技术如何解决实际问题：把业务流程梳理清楚，让系统落地运行，也让重复的工作尽可能自动完成。

我在做什么

企业业务系统开发

参与 ERP、OA、OMS、WMS、MES、DMS、TMS 等系统开发，围绕企业管理、订单处理、仓储物流与生产业务，将实际需求转化为可用的系统功能。

全栈与微服务开发

使用 Java、Spring Boot、Spring Cloud 进行后端开发和微服务落地，结合 Vue 2 / Vue 3 构建前端应用，并使用 uni-app 开发移动端功能。

AI 应用与自动化

开展 AI 应用开发，使用 Python 编写工具、自动化脚本和通用数据采集爬虫，也使用 AutoJS、EasyClick 和 RPA 实现重复操作的自动化。

设备通讯与系统对接

对接地磅等设备，通过串口通讯完成数据读取与业务系统集成，让现场设备数据进入业务流程。
